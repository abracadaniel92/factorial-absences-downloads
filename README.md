# Factorial Absences — downloads

Desktop app for macOS and Windows that finds approved vacations in Factorial that still lack a leave decision, and produces the documents after HR approves them.

This repository only hosts the installers. The source code is private.

## Download the latest version

- **macOS:** [Factorial-Absences-macOS.zip](https://github.com/abracadaniel92/factorial-absences-downloads/releases/latest/download/Factorial-Absences-macOS.zip)
- **Windows:** [Factorial-Absences-Windows.zip](https://github.com/abracadaniel92/factorial-absences-downloads/releases/latest/download/Factorial-Absences-Windows.zip)

All versions: [Releases](https://github.com/abracadaniel92/factorial-absences-downloads/releases)

## Installing

- **macOS:** unzip, move the app to Applications, then right-click it and choose **Open** the first time (the app is not signed yet).
- **Windows:** unzip the whole folder and run `Resenija.exe`. If SmartScreen warns, choose **More info → Run anyway** (the app is not signed yet).

The installers do not include any company document templates; they are added inside the app under Settings → Templates.
